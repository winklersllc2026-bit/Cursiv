Before You Download
Installing the Desktop App

Setting real expectations, so nothing on install day is a surprise.

●
Windows only, for now
64-bit Windows 10 or 11. ~6 GB free disk space minimum, 8 GB RAM minimum.
●
It downloads more after the installer finishes
The installer itself is a few hundred MB. After it finishes, it automatically downloads Ollama (~90 MB) and the llama3.1 AI model (~4.7 GB) — this is the biggest chunk, and it needs a real internet connection.
●
You'll see real terminal windows during setup
Each step (Git, Python, Ollama, the model, packages) opens its own titled window so you can watch progress. This is expected — it's not an error.
●
One optional prompt: "Download the Offline Code Council?"
You'll be asked [y/N] whether to also download two coding-specialist models (~18 GB total). Type N and press Enter to skip it — Cursiv works fully without it. Say Y only if you plan to use it for coding help and have the bandwidth/disk space to spare.
●
First launch
Double-click Cursiv on your desktop. First time in, you'll create a local username and password — stored only on your machine, never sent anywhere.

Optional Power-Up
Adding Your Own API Keys

Cursiv works fully offline out of the box, using llama3.1 running on your own machine through Ollama. If you want access to larger cloud models, you can add your own key from xAI, OpenAI, or Anthropic directly inside the desktop app's chat interface — this is a desktop-app feature, not something you configure on this website. The system always tries your local model first; a cloud key only gets used if you specifically ask for it, or if the local model isn't available. No key, no problem — nothing is required to use Cursiv.

Quick Answers
Frequently Asked
Do I need to install anything to use this website?
No. The demo chat works straight from your browser. Only the Chat page (the one that talks to your own local Ollama) assumes you already have software running on your machine — everything else needs nothing installed.
Is my data private?
The demo chat on this website is a limited, rate-limited public preview. The desktop app is fully private by design: nothing you type there is sent anywhere unless you add your own API key. That's also where the community board and sealed family letters live.
Why does the Chat page ask about Ollama and CORS?
The Chat page on this website talks directly to an Ollama instance running on your own computer, not to a server. If you haven't installed Ollama yourself, that page won't do much — the desktop app is the much easier way to get a working local AI without dealing with any of that manually.
Does the desktop app really work with no internet?
Yes, once installed. It needs an internet connection during setup to download Ollama and the model. After that, day-to-day use works fully offline — nothing you type is sent anywhere unless you've added a cloud API key yourself.
