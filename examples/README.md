# Example knowledge packets

JSON packets the Agent Factory (`cursiv_v215/forge/factory.py`) turns into agents:
the packet is encoded, scored by the Academy, and stored in the agent vault.

- `knowledge_base.json` — a general knowledge agent (emergency preparedness and other core domains)
- `personal_principles.json` — an agent built from a set of personal principles

Copy one, change the name, domains and content, and load it to make your own.
